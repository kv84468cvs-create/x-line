## X 时间线 · X Timeline v0.3.0

给 SillyTavern 用的第三方 UI 扩展：把当前聊天的剧情变成一条可以刷的 X（Twitter）黑蓝风格时间线。角色会用自己的口吻发帖、评论、转发，也可以和角色卡里的好友私信；配图优先接入「柏宝绘」，没有柏宝绘时回退到 SillyTavern 自带的 Image Generation。

整个界面是酒馆里的右侧抽屉（手机全屏），不另起网页、不需要单独服务器。顶部左侧头像打开个人/设置侧栏，底栏只有首页、搜索、社区、私信四项。


## 功能

- **跟着正文更新**：自动同步默认关闭；打开设置里的「自动同步正文（总开关）」后才会按频率消耗模型。也可以完全手动，点右上角刷新、设置里的「立即同步」或 `/xsync`。
- **X 风格界面**：首页「为你推荐 / 正在关注」、帖子详情与评论、个人资料、私信、社区、搜索；设置从头像侧栏进入，底栏保持四项。
- **评论与转发**：点评论图标直接进入详情看评论；可以评论任何人的帖子。模型同步时会一次生成帖子、评论和转发；NPC/好友的评论条数按该账号粉丝数计算（1–4 条）。
- **NPC / 好友发帖**：设置里可开关「允许 NPC / 好友发帖」。关闭后只有用户和角色卡角色发顶层帖，NPC 仍可评论和转发。
- **个人资料**：编辑自己的显示名称、@用户名、简介、所在地和头像；支持本地图片上传（自动压到 256px）或头像 URL。
- **角色与人物**：角色卡里的角色会同步到社区和私信；可以在资料页单独编辑角色/NPC 在时间线里的名称、头像、简介，不影响角色卡。社区页可「添加人物」，保存后正文里出现同名角色时会自动归到这个账号。
- **私信**：好友来自当前角色卡和群聊成员；名字/头像/简介跟随角色卡，自定义过则以时间线设置为准。发私信后可以让模型以角色口吻自动回一条。
- **当地趋势**：只根据当前角色卡的世界观、城市/机构/天气/公共事件生成，并附上「为什么成为话题」。私密场景或非公开地点不会生成趋势；没有合适话题就为空。
- **AI 配图**：优先调用柏宝绘公开 API（自动复用角色 tag 和它的并发队列），不可用时回退到 ST 的 `/imagine`；支持自动配图、概率、画风后缀、尺寸。
- **本地数据**：时间线按聊天保存在 `chatMetadata.x_timeline`，不写角色卡；设置里可导出 JSON 或清空。

## 安装

要求 SillyTavern **1.13.0+**（开发和测试基于 1.19.0）。柏宝绘是可选依赖，不装也能用 ST 生图。

1. 关闭 SillyTavern。
2. 把整个 `x-timeline` 文件夹放到：
   - `SillyTavern/public/scripts/extensions/third-party/x-timeline`，或
   - `SillyTavern/data/<你的用户目录>/extensions/x-timeline`
3. 启动 SillyTavern，打开「扩展」（魔杖图标）→「扩展」，找到 **X 时间线 · X Timeline** 并启用。
4. 刷新页面。打开方式：
   - 魔杖菜单里的「X 时间线」；
   - 或聊天输入 `/xfeed`；
   - `/xsync` 打开并立即同步。

> 新聊天的时间线是空的，先点空状态里的「从最近剧情生成」，或右上角刷新。

## 接入柏宝绘

1. 先安装并配置 **ST-BaiBai-Image**（建议 0.3.2+），在它自己的菜单里选好 NovelAI / ComfyUI 后端并测试能出图。
2. 回到 X 时间线 → 头像 → 设置和隐私 → 配图 → **生图通道**：
   - `自动`：默认。检测到柏宝绘且已配置时优先用它；失败自动回退到 ST `/imagine`。
   - `柏宝绘`：只用柏宝绘，失败直接显示原因。
   - `SillyTavern`：只用 ST 的 `/imagine`。
3. **保存到柏宝绘图库**默认关闭：图片只放在时间线里，避免图库膨胀。需要留档时再打开。

插件只调用柏宝绘的公开入口 `globalThis.STBaiBaiImage`（`apiVersion 1`）：

- `getBackendStatus()` 判断是否已配置；
- `getCharacters({ floor })` 取当前楼层角色卡对应的 Danbooru tag；
- `generate({ prompt, nl, characters, size, save, character })` 出图，拿 `dataUrl` 显示在推文里。

不会读取柏宝绘的 API Key，也不直连 NAI。柏宝绘报错会按 `error.code` 转成中文提示（未配置 / 限流 / 后端错误 / 参数无效 / 已取消）。

### 只用 SillyTavern 生图

在「扩展 → Image Generation」里配置好后端并测试能出图。插件执行：

```text
/imagine quiet=true gallery=false processing=minimal width=832 height=1216 <画面描述>
```

`quiet=true` 不会把图发到聊天，`gallery=false` 不会存进角色画廊。

> 柏宝绘返回的是 data URL，会存进当前聊天的 metadata。图片很多时会明显增大聊天文件；介意的话打开「保存到柏宝绘图库」并定期清理，或减少自动配图。

## 私信与好友

- 好友列表来自当前角色卡、群聊成员，以及剧情里出现且仍在关注的配角。
- 好友的角色卡名字/头像/简介会随角色卡更新；如果你在时间线里自定义过名称、头像或简介，则以自定义为准，不会被角色卡覆盖。
- 角色卡换头像时，插件会按角色 key/姓名匹配旧账号，不会因为头像文件变化把帖子和私信拆到新账号。
- 私信会自动带入角色简介、最近 10 条私信和最近 2 条正文，让回复贴合当前剧情。
- 设置里可以关闭「私信自动回复」；关闭后你仍然可以发消息，只是不会自动生成回复。

## 独立 API（可选）

头像 → 设置和隐私 → 独立 API：

- 打开「使用独立 API 生成时间线」后，同步、AI 评论、私信都会走这个 OpenAI 兼容接口，不消耗酒馆主 API。
- 填接口地址（写到 `/v1` 即可，也支持完整 `/chat/completions`）和 API Key。
- 点「拉取模型」从接口的 `/models` 读取列表；选中模型后点「测试连接」，测试的是刚刚选中的模型。测试通过后点「保存 API 设置」，否则重载页面会丢掉这次修改。
- 也可以不拉取，直接手填模型名再测试。
- Key 只保存在本扩展设置里，不会发到除该接口外的地址。

> 浏览器直连接口需要对方允许 CORS。若浏览器报 CORS/网络错误，请改用允许跨域的中转地址，或把接口部署在同源反向代理后。插件不经过 SillyTavern 服务端转发你的 Key。

## 同步、刷新与 token

- **自动同步正文（总开关）**：默认关闭。开启后，每收到 N 条角色消息触发一次同步（默认每 2 条）。
- **定时自动刷新**：默认关闭；只有总开关开启时才按间隔检查新正文。
- **手动**：右上角刷新按钮、空状态按钮、设置里的「立即同步」、`/xsync`。
- **省 token**：一次同步请求会同时生成推文、评论、转发和趋势，不需要为每条评论再调用一次模型；参考正文默认只带最近 3 条。
- 自动同步、自动刷新和私信自动回复都会消耗模型调用。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 自动同步正文（总开关） | 关 | 开启后才会自动消耗模型 |
| 定时自动刷新 | 关 | 面板打开时按间隔检查新正文 |
| 自动刷新间隔 | 1 分钟 | 30 秒 / 1 / 2 / 5 分钟 |
| 同步频率 | 每 2 条 | 积累多少条角色消息触发一次 |
| 每次生成数量 | 3 条 | 单次最多写入几条顶层推文 |
| 允许 NPC / 好友发帖 | 开 | 关闭后 NPC 只能评论/转发 |
| 参考正文条数 | 3 条 | 发给模型的最近正文数量 |
| 额外写作要求 | 空 | 追加到同步提示词末尾 |
| 自动生成配图 | 关 | 是否自动出图 |
| 生图通道 | 自动 | 柏宝绘 → ST，或强制其中一种 |
| 保存到柏宝绘图库 | 关 | 是否把图写进柏宝绘图库 |
| 配图概率 | 45% | 自动配图时的触发概率 |
| 画风后缀 | anime illustration… | 追加到画面描述 |
| 图片尺寸 | 832×1216 | 生图宽高 |
| 独立 API | 关 | 使用单独的 OpenAI 兼容接口 |

| 私信自动回复 | 开 | 角色收到私信后自动回一条 |
| 模拟互动数据 | 开 | 给新推文随机点赞/转发/查看数 |

## 使用说明

- **首次使用**：新聊天先同步一次，之后角色账号、推文、评论和私信会保存在这个聊天里。
- **评论**：点评论图标看详情；点「回复」写评论；`Ctrl/Cmd+Enter` 发布。
- **添加人物**：社区页右上角「添加人物」。保存前会提示该人物会与正文同名角色同步；这里只改时间线账号，不改角色卡。
- **定位正文**：推文详情里点「在正文中定位」，会跳回触发它的楼层并闪烁。
- **资料**：社区页或推文头像进入资料页；自己的资料页有「编辑资料」。
- **模型要求**：同步依赖模型输出严格 JSON。若经常解析失败，换指令遵循更好的模型，或把「参考正文条数」调小，并在「额外写作要求」里强调「只输出 JSON」。

## 关于「真实 X 帖子」

**没有做，也不能在当前插件里可靠地做。** 真实 X 时间线需要 X 官方 API 的 OAuth、付费额度或自建后端代理；浏览器扩展直接抓取/嵌入会受 CORS、登录态、反爬和 X 服务条款限制，而且会把用户的账号凭据暴露在页面里。这个插件的定位是「当前剧情的本地投影」，不是真实联网的 X 客户端。

## 已知限制

- 时间线是当前聊天的本地投影，不是真实联网的 X。
- 柏宝绘未安装/未配置时会自动回退到 ST `/imagine`；两者都不可用时推文里显示错误。
- 柏宝绘图片以 data URL 存在聊天 metadata 里，大量配图会让聊天文件变大。
- 独立 API 受浏览器 CORS 限制，不能绕过对方服务端的跨域策略。
- 中文角色名的 handle 会优先从角色头像文件名推导（`ailin.png` → `@ailin`），否则回退到账号 key。
- 一次同步生成所有评论会多花一点输出 token，但比逐条生成省得多；解析失败时本次不会写入。
